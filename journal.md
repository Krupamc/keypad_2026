## 3h 41m 48s logged
### FINALLY!
I finished writing all of the code for my macropad today. (I love procrastinating Fusion :) The macropad has a couple of functions. The rotary encoder will switch the layers on KMK. (0-2 right now but planned expansion to 0-4) The leds will light up according to the layer as well as all change color. The oled screen (up top) will display the current layer, an image, and the functions on the layer. On each layer the 4 different keys will do different functions

They are as such:
Copy, Paste, Redo, and redo.
CTRL + F, clipboard, File explorer, and Screenshot.
Pause/unpause, mute/unmute discord mic, defen discord, mute pc.

## 11h 25m 3s logged
### Case work!
Hey hey hey, I know it has been like three months but I can explain…

### Why so long?
Well to be honest, I do NOT like fusion. I hate geometry and by extension cad. This project is my first time ever doing it so it took a lot of youtube videos, advise, and procrastination to get here.

### The Case:
The case is pretty simple, it has the top piece with cutouts for the OLED, rotary encoder, keys, as well as holes for the LEDs to shine through. (I will fillet everything at the end) It also has holes for the heat inserts to melt into. The bottom case has the actual walls of the case, holes for the screws, standoffs for the pcb, as well as the USB C cutout.

This is definitely not my cup of tea lol.
